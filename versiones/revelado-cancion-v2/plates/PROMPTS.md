# Procedencia de las matrices

Creación: 29 de septiembre de 2026. Herramienta: `image_gen.imagegen`, integrada en Codex, modo de generación de imagen nueva, sin imágenes de referencia. Las matrices seleccionadas se conservaron localmente; no se publica el material raster. Las indicaciones describen un medio artístico, no una autoría histórica ni el estilo de un artista individual. El generador interpreta el motivo y no garantiza exactitud geográfica. No se afirma dominio público ni una licencia Commons para estas ilustraciones.
